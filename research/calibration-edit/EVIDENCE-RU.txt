Редактирование сохранённых калибровок: схема и сохранность
=======================================================

Статус и границы
---------------
crates/calibration-edit — чистая модель локального документа, no_std,
forbid(unsafe_code), без alloc/IO/COM/прошивки. Document содержит неизменный
импортированный original4096 и рабочую копию4096: суммарно8192байта.
Clone копирует обе области явно; это модель host CPS, не обещание приемлемого
расхода RAM/стека для прошивки. Undo history и файловое сохранение — внешний
host слой. В этом модуле физическая запись калибровок отсутствует.

Начальная проверка использует Calibration::parse: ровно4096байт и marker0x9A.
Контрольная сумма блока неизвестна. Эта проверка не обнаруживает произвольное
повреждение остальных байтов, не подтверждает модель аппарата или RF-точность.
Источник, исходный SHA256 и отдельная резервная копия остаются обязательными
данными происхождения, которые ведёт host приложение.

Общая схема
-----------
Все16-битные слова little-endian. Адреса относительно импортированного блока.
Descriptor имеет Field, Group, offset, width, mask, shift, bias, min/max,
русские label/detail, editable и Consumption. Дескриптор только информирует;
запись принимает Field и заново разрешает его, произвольный offset/descriptor
передать в writer нельзя.

value = ((raw_word & mask) >> shift) + bias.
При записи меняются только mask-биты. Остальные биты и байты сохраняются.
min/max — пределы представления кода, не безопасный RF-диапазон.

General:

 0       1     FF/0        0..255             marker, только чтение

об абсолютной неиспользуемости всех этих байтов firmware.

и114 скрытых точек. fields() ленивый ExactSizeIterator, без Vec.

Полные слова против масок UI
---------------------------
Related stock0x080054E0/54FA/5512/5528 читает TX deviation как FULL u16.
Поле TxDeviationRaw намеренно заменяет всё слово. GUI должен показывать
полное значение; редактор не превращает его в low12bit/0x3000+code.

Filters general8..11 читаются LDRB и передаются helper0x080038D0 без &7.
Field::Filter — полный raw byte; вне switch работает наблюдавшийся fallback.
Редактор не заменяет raw0xF0 на0 и не объявляет fallback хорошей настройкой.

Legacy SaveBand переписывает TX deviation как0x3000+UIlow12 и volume как
0xB000+(Gain<<4)+DAC, а SaveTuneData нормализует несколько других полей.
Эти преобразования намеренно НЕ перенесены: выбор одного параметра должен
оставлять непрошенные bytes/bits без изменений. Full-word изменения только
там, где это явно указанное выбранное raw-поле.

Consumption и labels диапазонов
------------------------------
Табличные строки/frequency offset/full deviation/filter подтверждены в
related путях, описанных в прежних отчётах. MIC, volume, compander, REG3E,
VOX tuning, battery table/ADC correction в рассмотренных применяющих путях
не наблюдались либо подменялись отдельной конфигурацией/константами.

Отдельно: selector0x08012CBE повторяет slot13 в последней частотной ветке;
slot14 не выбирается этим selector. Поэтому descriptors band14 не получают
RelatedStockTraced даже для структурно известных полей. Формат остаётся
известен, применение конкретной записи15 не объявляется доказанным.

Транзакции/сброс/экспорт
----------------------
set(Field,i32) — одиночная правка. apply(&[Change]) сначала проверяет ВСЕ
индексы, разрешения, значения и пересечения масок, потом меняет bytes.
Повтор одного поля запрещён даже при одинаковом значении. Непересекающиеся
Gain/DAC или compander parts одного слова допустимы в одном batch.
Ошибки оставляют original/working побайтно прежними. Третий4096byte буфер
для atomic validation не нужен. Для не более1666 changes проверка пересечений
ограничена; цена O(n²) — host-модель, не firmware realtime pipeline.

apply возвращает число реально изменённых ПОЛЕЙ, не байтов. dirty_count/diff
считают bytes относительно original; Diff выдаёт offsets по возрастанию.
reset_field возвращает только mask выбранного editable поля к original;
reset_all возвращает исходные4096bytes целиком. Это не factory defaults.
original(), bytes(), export_bytes() дают только immutable borrowed access.
Файловое сохранение/manifest/SHA256 выполняет host, а не эта библиотека.

Проверки
--------
14 tests подготовлены; Cargo/test запускает root. Они проверяют:
-1666 уникальных descriptors и независимую ожидаемую bit-coverage схему;
-сопоставление всех bands/tables с существующим parser и реальным fixture;
-каждое из1550 editable полей: разрешённая mask, original/unknown tail intact;
-для каждого поля обе границы и отклонение min−1/max+1/i32 extremes;
-raw full16/full8 без UI-масок, CTCSS/DCS bit7, volume reserved bits;
-signed offset-binary, atomic bad batch, overlapping batch rejection;
-shared-word disjoint masks/reset, readonly controls/hidden points;
-sorted byte diff, Clone независимость, reset exact original;
-length/marker-only import без checksum/default claims, hostile usize indices;
-источник и порядок band labels, сохранение неоднозначной подписи.

Данные calibration RF-performance, применение к радиостанции и восстановление
изменённых калибровок этими тестами не проверяются. Наличие editable поля
означает доказанную схему файла, а не рекомендацию менять заводской параметр.
