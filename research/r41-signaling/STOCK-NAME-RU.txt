Эталон: RT-880_Upgrade_V1_16_250915.nicsure.bin, адрес 0x08002800.
SHA256 eaef215cc7084dcd94281bbffb7ab6e2dd1e79ce135f01c90e3dbc691dd16bfc.
Первичный источник регистров: Beken BK4819 Application Note v1.0, §§7–8,

ИМЯ В CPS И ПАМЯТИ

Штатная CPS RT-880 v1.10, DM550_NOLCD/MainForm.cs: список Roger Beep
1899–1902, подпись Radio Name/Callsign 3927, чтение имени 12149–12153,
запись имени в GBK и дополнение FF 12671–12682, Roger Beep read/write 12285 и 12808.
Имя хранится в CFG[76..92), 16 байт, с заполнением FF. ASCII
в GBK занимает один байт. CFG[166]: Off=0, Roger 1=1, Roger 2=2,
MDC1200=3, GPS=4. Пункт CPS «MDC1200» выбирает эфирную передачу имени.
Программный Motorola PTT-ID имеет отдельный формат и свой UNIT ID.

В RT880 1.16 RAM CFG начинается в 0x200035EC. Чтение основного блока
08012438..08012444 через 08025D30(NOR 0x2000, 0x400 байт), проверка
CFG[0x0c..0x0e) == 11 11. Резервное чтение 08012490..0801249C
с NOR 0x3000. Штатный helper 0801F218..0801F22E вызывает 08025E40
для записи 0x400 байт с 0x2000. Это описание эталона, без записи NOR.

ПЕРЕДАЧА

08010338 обрабатывает конец TX. Для CFG[166]=3 последовательность
08010366..08010386 включает modem, копирует 16 байт из CFG+0x4C
в RAM 0x20001918 и вызывает 08004A3C. 08004ACC(1) задаёт
REG70=00E0, REG72=3065, REG58=37C3, REG5C=5665, REG5D=0F00.
REG58 задаёт FFSK 1200/1800 Гц. REG5D задаёт длину 16 байт.
REG5C[6] включает CRC. Затем REG3F=8000, REG59=8028 (очистка TX FIFO),
REG59=0028, восемь записей REG5F и REG59=2828 (TX со скремблером).
REG59[7:4]=2 задаёт 3 байта преамбулы, REG59[3] — 4 байта sync.
Два байта имени входят в слово REG5F старшим байтом вперёд.
В этом тракте sync не меняется. Reset в 08004DC0..08004DD6 и
проверенные точки вызова дают базу для REG5A=85CF, REG5B=AB45 из
строк reset value документации Beken. Rust выставляет их явно
после возможного использования другого формата на том же модеме.

Stock ждёт pending в REG0C по 5 мс, максимум 200 проверок, затем
пишет REG02=0. Rust использует REG02[15] TX finished после
acknowledgement и ограниченный foreground state machine. CRC,
скремблирование, порядок символов на линии и преамбулу реализует BK4819.
Верифицирован порядок байт слова FIFO. Форма сигнала, CRC на линии,
девиация и достижимость параметров на конкретном радио требуют эфира.

ПРИЁМ

0800B0A2..0800B0A6 выставляет тот же профиль и запускает 080049C0.
REG3F=2800 разрешает FSK RX finished и DTMF, REG59=4028 очищает RX FIFO,
REG59=3028 запускает RX с тем же скремблером. 0801D990 сначала читает
REG0B, подтверждает IRQ записью REG02=0, при REG0B[4]=1 (CRC PASS)
читает восемь слов REG5F в те же 16 байт. 0xFF в первом байте используется
для GPS. Для имени 0801DA0A..0801DA0E выставляет флаг на показ.
Из IRQ 0801DB8C передаёт управление обработчику popup. 0801F9A8..0801F9B2
даёт функции 0800C830 аргументы r2="MDC1200 Code:   ", r3=0x20001918,
r1=200. 0800C8B8..0800C8BE копирует ровно 16 байт текста. Размерность
таймера stock отдельно не проверялась. Имя передаётся из буфера станции
и выводится напрямую из буфера FIFO на другой станции.

Rust дополнительно проверяет REG02[13] для окончания FSK приёма.
DTMF остаётся отдельной причиной REG02[11]. Приём обычного FM работает
без включения передачи имени. CRC PASS и допустимый непустой ASCII (padding FF либо NUL)
дают временное окно на 3000 мс. Выбор имени и переключатель передачи
глобальные. При включённом имени оно занимает одну посылку после PTT;
числовой MDC в начале TX может использоваться вместе, если включён.

ОФЛАЙН ПРОВЕРКА

oracle.py запускает ограниченные процедуры образа с проверенным SHA
в Unicorn через research/stock_emu.py. Аргумент — путь к эталонному BIN.
Подставляются чтение/запись BK4819, ожидание и захват входа popup.
Старт с 08010338 ограничен возвратом из ветки имени. Эмулированная
GPIO-страница принимает первую штатную запись GPIOC BRR.
Два вектора: "AZ QX R0ABC" с дополнением FF и полные 16 байт
"QRST UVWXYZ 0123". При CRC FAIL FIFO не читается и окно не вызывается.
Это связывает запись CFG, переданный payload и popup на уровне
оригинальных инструкций ARM. Радио, порт и NOR не задействованы.
