Local document model
--------------------
work/uv98-rust-stage/crates/cps-core contains uv98-cps-core. Its library is
in-memory only: exact-length import; immutable original and working views;
transaction callback over an isolated fixed-size candidate; atomic rejection
on callback Err; inverse-patch undo; revert to original; changed byte ranges
grouped by section; export as an independent complete byte vector. No direct
mutable view of committed/original bytes escapes. No SHA dependency was added.
Callbacks are responsible for field validation, normally through codeplug APIs.
Unknown sections and fields are preserved unless explicitly changed.
Export does not alter the original baseline or reset dirty state.

Eight synthetic tests cover boundaries, invalid lengths, exact preservation,
grouped changes, transactional errors, undo, no-op history, revert, independent
export and integration with a valid/invalid channel patch. They embed no user
file contents. Root owns all Cargo/build execution; this agent did not run it.

The optional verify_document example takes explicit local input paths and
performs read-only file access outside the library. It checks no-edit byte-exact
export, an in-memory single-bit channel edit, unchanged Time, and undo restoring
every byte. It prints booleans and lengths only. It does not write source files.
The Python inventory script checks structure and hashes, not the Rust API;
native-files.json explicitly distinguishes those checks.
