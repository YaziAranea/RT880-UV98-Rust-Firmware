Расширение lossless CFG настроек; 2026-11-08

Источник: локально декомпилированный RT880 CPS1.10 MainForm.cs:
work/cps-analysis/rt880-v110-decompiled/DM550_NOLCD/MainForm.cs.
SHA2561096b3c280d1d279b321f504c936ffb3fc5553123ecd110d4505a7e77bd7234c.
DataToPanel читает array[offset]; SaveData записывает выбранный индекс/число
в тот же bufCFG[offset]. Все перечисленные поля занимают ЦЕЛЫЙ byte.
Маскирование не нужно: неизвестные соседние bytes остаются без изменений.
Это CPS layout evidence связанного RT880, не обещание одинакового поведения
всех функций на каждой ревизии UV98. Ничего не записывалось в радио.

Таймеры и единицы
LockTimer,LEDTimer,MenuTimer:0Off, затем5,10,15,30,45,...585,600 (43choices).
SaverStart имеет ту же числовую сетку, но label0="0". Код не равен числу
надписи. Key Lock Timer/LCD Timer/Menu Exit Timer/Save Start Timer не содержат
доказанной единицы; поэтому choice_label/timer_value НЕ добавляют секунды.
VOXDelay отдельно имеет явную надпись"VOX Delay (S)" и choices0,0.5,...5.
Секунды отображаются только для этого уже существующего поля.

API и сохранность
Field::ALL содержит24поля, label_ru/group_ru/choice_label не выделяют память.
choice_label возвращаетNone для unknown кода либо обычного numericcontrol.
Settings::code всегда возвращает исходный byte, в т.ч.0xF0/0xFF.
Typed decode ScanDirection/ScanMode/ScanReturn/TuningStep -> Option; unknown
не заменяется Off/default. Typed setters меняют только свой конкретный byte.
set_code проверяет диапазон до записи; ошибки сохраняют весь CFG.
Стоковый SaveData целиком НЕ переносился: он перезаписывает многочисленные
байты/defaults/GBKstrings и посторонние блоки. Наши patches адресные и lossless.
TX power/калибровочные таблицы, RF defaults, passwords, APOmulti-byte timers,
DTMF/APRS и создание каналов этим расширением не добавлены.
