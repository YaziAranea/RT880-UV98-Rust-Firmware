Oracle
python research/radio018/derive_oracle.py
Только Flash RX/RAM RW; MMIO отсутствует. Реальный исходный Thumb исполняет
выбор частотных калибровок, формулы, ветвления, последовательность регистров,
DCS кодирование09920/0994C. Заменены RF read/write,NOR read25D30 и delay8380.
12 точных GPIO-store PC сверяют адрес/маску и записывают событие вместо MMIO.
RF read использует согласованный register map; неизвестные чтения seed55A0.
Reset register00 не моделирует физический reset RF; delay фиксирует только
номинальный аргумент, а не время. --skip-tones переиспользует готовый tone.csv.

Наборы:7cold-prefix,1full-cold,4116tone,42completeTX,24completeRX,48audio,
1161AM-AGC,1024tone-status. Таблица AMgain97entries отдельно сравнивается.
Хеши CSV/fixture в oracle-summary.json. Исходная фабричная калибровка в эти
CSV не попадает: calibration синтетическая, её генератор и hex сохранены.
10 Rust integration tests сравнивают порядок/значения с CSV; этот агент Cargo
не запускает. Факт запуска/результат тестов фиксирует интеграционная сборка.

Crate API
crates/rf-sequence: no_std,forbid unsafe,no heap,immutable Plan максимум64Step.
WriteA,UpdateA,DelayMs,Mute,AntennaPf0,TxGates — запросы, не backend.
UpdateA=(fresh_read&keep_mask)|value; всегда повторное чтение перед записью.
TxGates(0..5) точно повторяет05354: PC15LOW,PB11LOW,read33&FFF3,
route1 PC15HIGH/PB11LOW;2 PC15HIGH/PB11HIGH;3 bit3;4/5 bit2;write33 last.
Реле PF0 этот helper не переключает. Root executor отдельно владеет GPIO,
PTT,временем,watchdog,снятием TX при ошибке и проверками readback.

FM/AM audio
050EA..518E с channel[0]=0 вызывает38AC(1),A47=6140 и gain/DAC CFG.AE/AF.
channel[0]=1 вызывает38AC(7),A47=6740 и отдельную пару CFG.B0/B1.
Оба формируют48=B000+(gain<<4)+DAC с исходной16bit арифметикой, затем
05768 корректирует по полному freshA01. Функции audio_mode_word и
audio_volume_word сравниваются с48полными исходными slice executions.
PF8 открывает внешний runtime после настройки/settling/squelch policy.
AM software AGC024140..0242AC перенесён вam_agc::State::sample:
RSSI67,история,target142,gainindex1..96,250tickdecay,таблица3B,
write13 at02428A. Точный init02E50/02E5C:index90,previous0,hold0.
1161переходов сравнены с оригинальнымARM,включаявсе512RSSIисходаindex90.
State::sample возвращаетrequest register13 и новыйState; executorисполняет
его только вAM с активным AF/RXstate2. Timer/dispatcher теперь проверен:
номинальный1ms countdown, не чаще1sample/foregroundпроход. 250 означает
числоAGCвызовов, НЕточныеms при задержкахUI. См.AM-RUNTIME-AUDIT-RU.txt
и runtime-evidence.json: IRQ/dispatcher/gates проверены отдельно.
ИзмереннаяAMустойчивостьнаживомжелезеэтимнеподтверждается.

Subtones
None raw0:51=0. CT raw1xxx:51=9041,07=floor(payload*413/200)&1FFF.
DCS raw2000..21FF /3000..31FF:51=802C/A02C,07=0AD7,08lower12 затем
08=8000+upper. Оригинальный09920/0994C выполнен для всех512code,обеих
полярностей,4toneMode. toneMode1/3 выбирает alternateGolay, не polarity.
Неподтверждённые rawtypes/modes>=4 отвергаются, не превращаются вnone.
Band CT/DCS deviation bytes сохраняются; их потребление здесь не доказано,
поэтому вместо stock immediate не используются.

Интеграционные требования
PTT release-to-arm;каждый переход ограничен временем;TOT независим от UI;
TXfreq/tone берутся из TXполовины канала,Reverse меняет ОБЕ пары RX/TX.
На отпускание/error/TOT сначалаPC15/PB11/PF8LOW иboundedA33off/A36=007F/
A30=0 (при terminal можноA33=0 без небезопасного read ожидания),затемRX.
RX::stop старой crate толькоmute и не заменяет TXshutdown.
Никакая ошибка шины не должна оставлять firmwareвбесконечномпитанииWDT
при возможномактивномTX. Watchdog recovery требует earlyoff доRF/UI.
Проверять every-prefixfault,PTTнакаждомшаге,stuckPTT,TOT,clockwrap/reversal,
retuneотмену,переходRX/TXмеждудиапазонами,повторныйrelease,recoveryboot.
Backend/логика shutdown/таймеры принадлежат root; этот pureplan их не создаёт.
