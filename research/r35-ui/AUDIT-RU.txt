crates/handheld-ui/fonts/README.txt. Both physicalLCD and simulator use the
same4368-byte 2bpp subset, all digits26x48. No runtime rasterizer or new heap.

HF screen (SCANNING -> HF / RADIO)
Long0 toggles measured32-bin RSSI sweep +16-row waterfall. Not FFT, audio
is interrupted during the sweep; EXIT restores selected tuning. Reopen HF
starts listening. Changing band cancels scope. Arrows move selected tuning.
Long1 AM filter6/3/1kHz; long2 AM soft mute. SSB retains long1/3 BFO adjust,
long2 BFO reset. Bottom side key remains tuning-step selector.
Ring belongs to App and is borrowed by Model, not copied into each View.
Only a fully measured row enters history; grid reset discards old samples.

Menu / volatile settings
MODE -> BAND PRESET: VHF145.500 FM / UHF433.500 FM /
CB27.135 AM step10kHz / 800-band850.000 FM step25kHz. This selects a
frequency, not an independent forced relay bit. Root RF routing owns relay.
GPS/APRS: GPS power, baud, status, manual APRS. Callsign and active TX
frequency displayed on beacon page; unsupported modem distinct from nofix.
SYSTEM / TX: held-TX keypadDTMF enabled, end-TX Off/ZVEI1/CCIR, five-digit ID.
The button diagnostic item was removed from System. Diagnostic screen remains
available via assignable shortcut Keys (default long8), not a separate menu item.
No ID by default. ID editor accepts exactly5 digits; #clears; MENU saves;
EXIT cancels. Numeric5-tone does not pretend to transmit arbitrary names.
