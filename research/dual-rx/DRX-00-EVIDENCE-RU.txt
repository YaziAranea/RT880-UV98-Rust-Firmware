# DRX-00 — аппаратная возможность одновременного A/B RX

Дата: 2026-11-10. Только offline: схема, stock disassembly, host-модели.
COM/прошивка/RF/PTT не запускались; калибровки, NOR, codeplug и старые
релизы не изменялись. Production-образ не получил новых B MMIO.

## 1. Вывод

**Ни одна пара одновременно работающих приёмников не подтверждена.**
Для related-схемы RT880 V2 вторичный BK4819 (U400/B) не имеет доказанного
подключения RX-входа к антенне; последовательный C433 на линии EARO помечен
NC (NC относится к C433, не к самому выводу EARO); аудиотракт — один
аналоговый селектор, а не микшер. Поэтому:

- для RT880 V2 по этой схеме B-RX **unsupported** для этой ревизии: схема не
  показывает подключённый вход B к антенне и установленную связь C433; пока
  иное не доказано для конкретной платы;
- для пользовательской UV98 Plus ревизия не установлена, поэтому статус
  **unverified**, а не «работает» и не «физически невозможно»;
- требование «оба сигнала слышны одновременно» без внешнего микшера/двух
  трактов **не поддержано**; PC4 выбирает один источник.

Прошивка не создаёт соединение, которого нет по схеме. B остаётся asleep;
новых GPIO/регистров для B в рабочем образе нет.

## 3. Матрица DRX-00

Обозначения: **P** — подтверждено программно/наблюдением, **S** — по related
схеме, **U** — не подтверждено.

### A / U201

| Звено | Факт | Статус |
|---|---|---|
| chip | U201 BK4819, отдельная 3-wire шина | P |
| RF input/antenna | основной антенный путь через K200/фильтры; A RX реально работает на станции (r5) | S + наблюдение владельца |
| filters/relay | PF0/K200, A33 route; общий антенный узел | S/P |
| calibration | factory 4096-байтный блок используется primary | P |
| init/wake | 08004DC0, RX start 08004FA0 | P |
| freq/mod/width | 08004B88, selector mode0; width helper A43 | P |
| RSSI/SQL/tone/AGC | A67 raw9, A0C bit1, tone path bounded; AM AGC отдельный | P |
| AF output | AFOUT4819 → U501 SW1 NC0 → AUDIO; PF8 global mute | S/P |
| speaker | один аналоговый тракт | S |

Точная электрическая чувствительность/калибровка dBm и ревизия PCB UV98 Plus
этим не доказаны.

### B / U400

| Звено | Факт | Статус |
|---|---|---|
| chip | U400 BK4819, CS PC7/SCK PC8/DATA PC6 | P |
| RF input/antenna | LNAIN pin15 → L400 47nH → C461 100pF → открытый верхний конец; антенной/именованной сети нет. Ветки ANT→B на стр.2 не найдено | S; для UV98 Plus U |
| filters/relay | отдельного B-антенного фильтра/ветки нет; B33 bit4 A/B-SW связан с TX-питанием U403, не с антенной | U/S |
| calibration | отдельная B-калибровка не установлена; secondary получает только 38/39 | U |
| init/wake | 08003D34; sleep 08003EC0; RX start 08003E3C | P |
| freq/mod/width | 08003CCC; secondary selector обычно не меняет RX route; A43 helper нельзя механически перенести на B43 | P |
| RSSI/SQL/tone/AGC | штатный B67 caller/B squelch/tone не найден; A-формулу нельзя переносить | U |
| AF output | EARO pin8 → C433, помечен **NC** → AF OUT4819B (не MOD4819B) | S |
| speaker | U501 SW1: NO1=MOD4819B, NC0=AFOUT4819; PC4 выбирает один источник, не оба; микшера нет | S |

Трассировка U400/B, стр.2 (пересечения без точки не являются соединением):

| pin | компонент | сеть/окончание | примечание |
|---|---|---|---|
| 15 LNAIN | L400 47nH → C461 100pF | открытый верхний конец | RX-вход B к антенне не показан |
| 14 MICP | C431 105P (маркировка схемы) | GND | C431 относится к MICP, **не** к LNAIN |
| 13 MICN | C489 105P (маркировка схемы) | MOD4819B | modulation/mic-сеть, не RX-аудио B |
| 8 EARO | C433 (NC) | AF OUT4819B | выход B по схеме не установлен |

LNAIN не объявлять заземлённым: C431 — отдельная цепь MICP→GND, а L400/C461
заканчиваются открытым концом. MOD4819B — не аудиовыход второго приёмника;
это modulation/mic-сеть, выбираемая U501/PC4 наряду с AFOUT4819. Даже если
C433 был бы установлен, один SPDT-селектор U501 не даёт одновременного звука
обоих RX. Схема RT880 V2 не доказывает подключённый вход B к антенне и
установленную выходную связь C433; ревизия UV98 Plus остаётся unverified.

## 5. Что изменит вердикт

Минимальные факты, каждый — отдельно:

1. Фото/прозвонка именно UV98 Plus: путь B LNAIN→L400→C461 и его верхний
   конец; отдельные C431 (MICP→GND), C489 (MICN→MOD4819B), C433/EARO;
   установлены ли U400 и B-shield. Не связывать LNAIN с MICN/MOD-цепью.
2. Подтверждённая ревизия платы и соответствие её схеме RT880 V2.
3. Read-only наблюдение B RX на этой станции без изменения stock/NOR/
   калибровок; проверить EARO/C433/AF OUT4819B и отдельно установить дальнейший
   путь к усилителю/динамику. Связь AF OUT4819B→U501 не доказана.
4. Документированный микшер/два выхода, если нужны оба звука одновременно.
5. Для Si4732 — отдельная проверка R-12, не «второй BK».

До этих фактов — только capability-модель, mocks и docs. Разборку корпуса
сейчас не запрашивать; это вечерняя задача владельца, если он решит.

## 6. Код и границы

- `crates/radio-runtime/src/capabilities.rs` — pure модель:
  `LogicalSlot → PhysicalReceiver`, `PairStatus`, `AudioCapability`,
  `tx_backend`, `simultaneous_rx_supported() == false`.
  Никаких MMIO/GPIO; модуль не подключён к production scheduler.
  `receiver_for_slot(B) → SecondaryB` — гипотеза DRX-01, не production.
- `research/dual-rx/DRX-00-capabilities.json` — machine-readable матрица
  с источниками/confidence.
- Host-тесты: ни одна пара не supported; B-пары unverified с причиной;
  дубликаты unsupported; TX через B запрещён; audio не mixer.
- Production B остаётся asleep; новых B MMIO/GPIO нет. Существующая
  channel-tx policy и TOT не изменялись.

## 7. Ограничения

Схема RT880 V2 — related, не фотография UV98 Plus; stock SHA — related
application, не MCU-readback пользовательской рации. Никаких электрических
измерений, фото платы, COM или RF в этом этапе не было. PAN/DMA/водопад,
AM/ATIS, TX-stop/TOT, нижний PTT, GPS/APRS/DSP не закрываются этим этапом.
