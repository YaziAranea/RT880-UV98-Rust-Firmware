Профиль UV-98 Plus / RT-880 для офлайн-прототипа Rust
Дата проверки: 2026-11-08. Устройство не подключалось этим исследователем.
Это профиль сборки и проверки ELF, не разрешение или инструкция по прошивке.

Предлагаемая карта памяти

  Цель: thumbv7em-none-eabi, Cortex-M4, программная арифметика float.
  FLASH: начало 0x08002800, размер 0x3D800 = 251904 байта = 246 KiB.
         Конец диапазона, не включая его: 0x08040000.
  Первые 0x2800 = 10240 байт Flash оставлены существующему загрузчику.
  RAM: начало 0x20000000, размер 0xC000 = 49152 байта = 48 KiB.
       Конец диапазона, не включая его: 0x2000C000.
  Начальный стек: стандартный верх RAM 0x2000C000, выравнивание 8 байт.
  Таблица векторов: начало FLASH, то есть 0x08002800.

Эта карта подтверждается целью проекта fagci/rt880-fw и документацией
AT32F423xC. Маркировка MCU и ревизия именно пользовательской платы не
проверены. Верх RAM не подтверждён физическим чтением устройства.
Резервирование области загрузчика в linker script само по себе не защищает
её от mass erase внешним программатором. Сейчас сохраняется только ELF;
образ для загрузки и процедура прошивки не требуются.

Сравнение стеков: не смешивать разные источники

  Публичная RT-880 1.16, файл
  work/reference-firmware/RT-880_Upgrade_V1_16_250915.nicsure.bin:
    первые 8 байт c8 99 00 20 c1 2a 00 08;
    MSP 0x200099C8; Reset 0x08002AC1 (Thumb), размер 251904;
    SHA256 eaef215cc7084dcd94281bbffb7ab6e2dd1e79ce135f01c90e3dbc691dd16bfc.
  Локальная RT-880 1.14:
    MSP 0x200099B8; Reset 0x08002AC1;
    SHA256 c073f3dd7fbc362520889669228a42744a84a58c0b3709daab5af8eef403db0f.
  fagci/linker.ld: _estack = 0x20009A68, комментарий «из стоковой прошивки».
    Версия и экземпляр исходного стока этим комментарием не установлены.
    Это НЕ измерение MSP пользовательской UV-98 Plus.

Все три значения MSP находятся внутри 48 KiB RAM и выровнены на 8 байт.
MSP обозначает выбранное начало стека, а не аппаратный размер RAM.
Различия не доказывают резервирование памяти выше стока и не требуют
копировать старое значение в новый самостоятельный прототип.
Точный образ пользовательской UV-98 Plus 1.16 не извлечён из её MCU.
Предоставленный установщик UV98 не анализировался после блокировки Defender;
публичный RT-880 BIN нельзя объявлять побайтово идентичным её прошивке.

Начальный запуск cortex-m-rt

  Использовать linker script link.x с собственной memory.x; таблица векторов
  должна начинаться ровно с 0x08002800. Этот адрес кратен 0x800, 0x400 и 0x200.
  Включить set-sp и set-vtor: runtime загрузит MSP из _stack_start и установит
  VTOR по адресу своей таблицы векторов до инициализации RAM.
  Без PAC допустим стандартный runtime без feature device: неиспользуемые
  IRQ получают DefaultHandler. Не включать device без полной таблицы IRQ.
  Сохранять обычную инициализацию .data/.bss; skip-data-copy не обоснован.
  Не включать zero-init-ram/paint-stack без отдельной потребности.
  thumbv7em-none-eabi соответствует soft-float сборке fagci. Переход на
  eabihf/FPU — отдельное решение; для простаивающего Stage 0 он не нужен.

Неизвестный контракт перехода из штатного загрузчика остаётся ограничением.
set-sp/set-vtor не сбрасывают CONTROL, NVIC, SysTick, DMA, watchdog, clocks
или GPIO. Отключение IRQ только в main происходит уже после startup.
Отсутствие кода TX не доказывает состояние RF-выходов, унаследованное от
загрузчика. Поэтому idle + IRQ disable + WFI пригоден сейчас для проверки
компиляции и ELF, но не является проверенным безопасным запуском на рации.
Перед физическим запуском нужны контракт загрузчика и отдельная проверка
ранней инициализации. Rust-функция pre_init до готовности RAM не предлагается.

Границы сохранённого бэкапа

  Ранее исследованная команда 0x52 читает внешнюю SPI NOR обычной командой
  0x03: адрес = индекс блока * 1024. Блоки 0..4095 покрывают 4 MiB main array.
  Подтверждение: публичная RT-880 1.16, handler 0x0801BDC8,
  сдвиг 0x0801BDF0, SPI read 0x08025D30; схема RT880 V2.pdf, стр. 3,
  U509 W25Q32, SPI2, PB12..PB15. Пользовательская ревизия отдельно не сверена.
  Эти 4 MiB не включают внутреннюю Flash MCU, штатный загрузчик, конфигурацию
  защиты, SPI OTP/security/ID и память отдельных GPS/APRS-модулей.
  Полный бэкап MCU без установки другой прошивки пока НЕ подтверждён.
  В исследованном application parser команды чтения MCU не найдены;
  загрузчик не содержится в публичном BIN и этим разбором не исследован.
  Защиту чтения не отключать ради бэкапа: это может стереть исходную память.
