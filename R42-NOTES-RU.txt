R42 — управление и проверка на рации

Экспериментальная пре-альфа; установка на свой страх и риск, без гарантий.
Сначала подготовьте персональный BIN R42 через имеющуюся CPS0.8 и свой
проверенный снимок NOR. Не используйте старый UV98-personal.bin от R41.
После прошивки: MENU → СИСТЕМА / TX → О ПРОШИВКЕ:0.1.8-r42.
Обычный RU файл:UV98-r42-ru.bin. Диагностика PA5 — отдельный RX-only образ.

1. Меню: пролистайте несколько пунктов вверх/вниз, затем смените группу.
   Заливка сохранена; актуальное выделение получает первый пакет LCD.
   При нажатии PTT/смене клавиши длинный пакет прерывается между окнами
   до6строк. Заявлений об измеренной частоте кадров нет.
2. Имя: СИСТЕМА / TX → ИМЯ РАЦИИ. Повторные нажатия цифр выбирают букву;
   0 — пробел, UP — подтвердить текущую букву, * — удалить, MENU — сохранить.
   «Имя после PTT» включить отдельно. После подтверждения настройки дождаться
   сообщения «НАСТРОЙКИ СОХРАНЕНЫ». Пустое имя не передаётся.
   На разрешённой частоте проверьте посылку второй рацией сначала без RX-тона,
   затем с тем же CTCSS/DCS; отдельно проверьте её распознавание штатной RT880.
   Тесты кода не доказывают совместимость эфира. Морзе не используется.
3. Репитер: выберите обычный VFO A с нужным сдвигом/тоном. Сравните короткий
   ответ сразу после PTT при выключенном «Имя после PTT», затем включите имя.
   Пока сама посылка передаётся, эта рация ещё не может слушать ответ.
   RX возвращается на выбранный VFO. Автоматического ожидания ответа на B нет.
4. КВ: в приёмнике удержать0 для обзора. Короткое# меняет8/16/32точки.
   8 быстрее,32 подробнее. EXIT возвращает прослушивание. Первый холодный
   запуск SSB включает загрузку патча; это отдельная задержка.
5. Микрофон: СИСТЕМА / TX → МИКРОФОН. UP/DOWN выбрать0..31, MENU сохранить,
   EXIT отменить. 0 не выключает микрофон. Сравните одинаковую фразу с одним
   расстоянием до микрофона на второй рации. Слишком большое усиление может
   искажать речь. Изменение не меняет выбранную мощность и девиацию.
6. После выключения/включения проверьте имя, Roger и усиление микрофона.
   Полная перепрошивка стирает их журнал. Другие настройки остаются в RAM.
7. PA5: отдельная инструкция research/r42/PA5-TEST-RU.txt. Нужны реальные
   захваты тишины/речи, прежде чем выбирать реализацию обработки аудио.

Ранее запрошенные функции сохранены: сегменты батареи и вольтаж; L/M/H;
верхнийPTT A/нижнийPTT B независимо от выбранного окна; RX/TX рамки;
автоматический FM DTMF; CB40каналов с выбором нулей/пятёрок и+2кГц наTX
CB AM; три отдельные локали; мультиязычная независимая CPS. SelectV убран.
DSP шумоподавление не заявляется готовым без подтверждённого аудиотракта.
