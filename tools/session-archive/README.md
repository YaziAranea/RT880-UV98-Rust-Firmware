# Архив инструментов исходной аппаратной сессии

Эти файлы сохранены без изменения протокола, ограничений устройства и SHA.
Они ожидают исходную структуру workspace с `work/uv98-rust-stage/` и `outputs/`.
В обычном clone их относительные пути не подходят; это документированный архив,
а не готовый переносимый установщик.

Перед будущим переносом инструмента нужно отдельно сохранить точные проверки
образа/модели/восстановления и проверить поток пакетов независимым oracle.
Не обходить проверки только ради запуска скрипта из другой директории.
