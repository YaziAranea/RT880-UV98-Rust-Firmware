UV98 Rust — интерфейс, кнопки и график активности, 2026-11-08

Запуск прототипа
  simulator/UV98-Radio-UI.exe
  Для переносного запуска держите libunwind.dll рядом с EXE.
  Установки и COM-порта приложение не требует.
  Можно открыть 999.880dmf или .98pdmf через кнопку открытия файла.
  Файл читается, не перезаписывается. Из него берутся каналы; сигнал всегда DEMO.

Управление
  Стрелки — предыдущий/следующий активный канал, с переходом через край списка.
  Цифры + Menu/Enter — номер канала (1..1024); Exit/Esc отменяет ввод.
  Menu → Spectrum → Menu — экран графика.
  На спектре стрелки перемещают курсор; Menu открывает Reset peaks / Back.
  Exit возвращает к каналу. Пауза и продолжение доступны кнопками ПК.
  PTT/пробел останавливает обзор и возвращает к каналу, передатчик не включается.
  Отпускание PTT не возобновляет обзор автоматически.
  Эта раскладка выбрана для нашего прототипа; идентичность стоковым жестам не заявлена.

Что готово
  uv98-ui-core: no_std контроллер каналов, цифрового ввода, меню, спектра и PTT.
  uv98-spectrum: no_std последовательный обзор, до 240 точек, явные подтверждения
  настройки/чтения, таймауты, отмена, маркировка проходов и удержание пиков.
  uv98-radio-ui: общий для ПК и будущей прошивки рендерер 320x240 RGB565,
  буфер строки 640 байт. Большая частота, имя/номер, график, частота курсора,
  сырые значения и пики. Предыдущий проход показан более тёмным цветом.
  uv98-keyscan-at32: opt-in GPIO-сканер матрицы и отдельного PTT по исследованной
  родственной плате. Два прохода, контроль отпущенных строк, open-drain колонки,
  неоднозначные сочетания/ghosting отклоняются. ADC боковых кнопок и энкодер
  здесь ещё не подключены. Физический scanner пока не соединён с runtime UI.

График прототипа
  Встроенные искусственные сигналы; никакого чтения эфира.
  Демонстрационный диапазон: +/-1 МГц от RX выбранного канала, шаг 12.5 кГц,
  161 точка. Значения RAW 0..1024 — выбранный масштаб рисунка, не dBm.
  Частоты из файла не доказывают допустимый аппаратный диапазон.
  Пауза/ошибка оставляет прошлые точки с явным состоянием STOPPED/ERROR.
  Нет FFT, водопада, захвата/прослушивания найденной активности или TX.
  Границы/шаг пока фиксированы в host-demo; Engine принимает явный диапазон.

Состояние физической рации
  Новая прошивка не загружалась, COM не открывался на этом этапе.
  Заводская калибровка и сохранённый NOR-бэкап не изменялись.
  4 МиБ сохранены из внешней SPI NOR; это НЕ полный бэкап MCU/загрузчика.
  Exact UV98 MCU-образ и проверенное восстановление по-прежнему отсутствуют.
  ARM cross-build подтверждает сборку библиотек, не исполнение на рации.
  Stage0 остаётся диагностическим WFI-каркасом; это не рабочая прошивка и не
  образ для заливки. Приём, звук, RF-init, физический экран/клавиатура и точное
  применение калибровок к RF ещё требуют интеграции и проверки на устройстве.
  Open-drain отличается от исследованного stock push-pull; допустимость проводки
  пассивной матрицы должна быть подтверждена. Ошибка/ambiguity ввода требует
  release-to-rearm в будущем аппаратном адаптере, а не превращения в Released.

Дальнейшая работа
  Подключить проверенный RX backend к Engine, использовать сохранённые калибровки,
  подтвердить настройку частоты/полосы и чтение уровня. Затем измерить скорость
  обзора, добавить параметры диапазона, пресеты, историю активности/водопад.
  Перед прошивкой — закрыть вопросы точного MCU-образа/загрузчика/восстановления
  и безопасного аппаратного старта. UI и новые функции можно развивать отдельно.

Сборка
  Распаковать source.zip. В каталоге uv98-rust-stage:
    ./build.ps1
    ./build-radio-sim.ps1
  Нужны Rust с target thumbv7em-none-eabi, Python 3 и зависимости Cargo.
  Скрипты меняют PATH/linker только в текущем процессе.
  Для PNG без GUI: UV98-Radio-UI.exe --preview NEW_DIRECTORY [FILE.880dmf]
  NEW_DIRECTORY должен отсутствовать; существующий каталог отклоняется.
  preview-report.json явно отделяет synthetic data и физические проверки.

Архив
  source.zip содержит исходники, тесты и локальные отчёты проекта, включая
  4096-байтовую калибровочную fixture именно этой станции. Не публикуйте её
  случайно вместе с общедоступным репозиторием. Полный NOR и файлы CPS в архив
  не вложены. preview содержит локальные изображения выбранных каналов.
  Идеи UI: research/ui/INSPIRATION-RU.txt (Karina/Egzumer); чужой код не скопирован.
