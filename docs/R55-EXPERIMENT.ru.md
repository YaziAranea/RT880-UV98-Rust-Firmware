# R55. Голосовая кнопка и поиск тона SmarTrunk II

Это два отдельных экспериментальных образа RT-880 / UV-98 Plus с русским основным интерфейсом. Выбор образа в CPS определяет, какой опыт доступен на станции. В комплекте Windows CPS 0.9.0. Исправленный голосовой образ показывает VK1 на главном экране и R55-VK1 в сведениях. PA5 и R55-CT соответственно обозначают диагностику приёма.

## Передача фразы

1. Распакуйте весь комплект и откройте `UV98-CPS.exe`. Выберите вкладку прошивки и исходный `RT880-R55-VK1-RU.bin`. По умолчанию в нём записана фраза «Проверка связи» длительностью 1,13 с.
2. Чтобы поставить свою фразу, нажмите «Добавить голосовой WAV…», откройте PCM WAV длительностью до 1,5 с и сохраните под новым именем. CPS принимает моно или стерео, целые 8/16/24/32 бита, от 4 до 192 кГц. Стереоканалы складываются в моно. Отредактированный исходник будет выбран автоматически. Для штатной персонализации укажите проверенный снимок **этой** станции. [Прошивка и персонализация](GETTING-STARTED.ru.md)
3. На главном экране выберите обычный разрешённый FM-канал. Проверьте, какой слот назначен нижней боковой кнопке (PTT A, PTT B или активный), и выставьте на нём частоту. Удерживайте только нижнюю PTT. Для старта записи до штатного тайм-аута передачи должно оставаться больше 1,525 с. После штатного начала TX и начальной сигнализации фраза проигрывается один раз. Отпускание прерывает фразу и завершает ручную передачу. Если продолжать держать кнопку, после фразы можно говорить в микрофон. Верхняя PTT работает с микрофоном. Остальные назначения нижней кнопки сохраняются.
4. На частоте эхо-репитера зажмите нижнюю PTT. Дождитесь конца фразы (около двух секунд после начала TX), произнесите «контроль» в микрофон и отпустите PTT. Послушайте, какие слова вернулись в эхо. Если вернулось только слово «контроль», отметьте, слышали ли «Проверка связи» в динамике самой станции во время передачи. Вся проверка выполняется одной рацией.

На установленной R55-VK эхо-репитер вернул передачу без записанной фразы. В этом образе настройка сторожевого таймера выставляла глобальную маску прерываний после её снятия. Процессор не вызывал обработчик TMR2, подающий отсчёты на ЦАП. В R55-VK1 маска снимается после успешной настройки сторожевого таймера. Слышимость фразы через микрофон и эхо-репитер проверяется на плате.

В этом опыте ЦАП2 выдаёт запись на PA5, прошивка открывает усилитель динамика, а передатчик продолжает использовать штатный микрофон. Проверяем, достаточно ли акустической связи динамика с микрофоном конкретной платы. Прямое проводное соединение ЦАП с модулятором не установлено. Начните с умеренной громкости. Разборчивость, уровень девиации и наличие щелчка на фронтах проверяются по демодулированному сигналу. Слот в прошивке занимает 3020 байт, использует IMA ADPCM 4 кГц, ЦАП тактируется на 8 кГц. Смена записи требует нового персонализированного BIN.

## Поиск 1400 Гц

`firmware/RT880-R55-CT-RX-only-RU.bin` — приёмная диагностика. При открытом FM-приёме на экране захвата PA5 нажмите **5**, пока идёт тон. **0** делает тихий контроль при закрытом звуковом тракте. После захвата появится `1400 Hz CANDIDATE`, `NO 1400 Hz CANDIDATE` или `1400 Hz: CLIPPED`. **#** выгружает исходный блок через диагностический UART. Анализ выполняется по команде, один блок длится около 256 мс. [Детектор и методика](../tools/smartrunk-rx/README.ru.md)

Для первой проверки на ПК из корня распакованного комплекта запустите `python tools/smartrunk-rx/inspect_collect_tone.py examples/control-1000-1400.wav`. В файле сначала идёт 1000 Гц, затем 1400 Гц. Ожидается один кандидат во второй половине. Такая же команда принимает WAV с приёмника после FM-демодуляции.

Контроллер SmarTrunk II использует Collect Tone 1400 Гц перед цифровым вызовом. Такой же тон от другого источника даёт тот же результат. Декодирование BPSK, номера абонентов и установление соединения ещё открыты. Следующий содержательный опыт — снять и сохранить сигнал контроллера целиком с началом цифровой посылки. [Руководство производителя, §3.2](https://sicom.ru/files/products/1169/smartrunk-st853-man-rus.pdf)

## Повторение сборки

Из корня исходников с установленными Rust и целью `thumbv7em-none-eabi` соберите нужный вариант. Экспортируйте его до сборки следующего. Для каждого экспорта нужен новый каталог.

```text
cargo build --locked --release -p uv98-diag-firmware --target thumbv7em-none-eabi --features channel-tx,voice-keyer,locale-ru
python tools/export_diagnostic_image.py target/thumbv7em-none-eabi/release/uv98-diag-firmware out-vk
python tools/check_flash_budget.py out-vk/UV98-diag-0.1.8.elf --language ru --profile voice-keyer --report out-vk/budget.json
python tools/check_voice_irq_startup.py out-vk/UV98-diag-0.1.8.elf
python tools/check_voice_clip.py out-vk/UV98-diag-0.1.8.elf
cargo build --locked --release -p uv98-diag-firmware --target thumbv7em-none-eabi --features pa5-audio,locale-ru
python tools/export_diagnostic_image.py target/thumbv7em-none-eabi/release/uv98-diag-firmware out-ct
python tools/check_flash_budget.py out-ct/UV98-diag-0.1.8.elf --language ru --profile pa5-audio --report out-ct/budget.json
```
